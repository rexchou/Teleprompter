## 1. 视频录制提词模式 (Video Prompter Mode)

### 1.1 核心痛点突破：“贴镜防眼神飘移”
市面传统提词器的通病是**“眼神乱飘、不看镜头”**——创作者视线往往在全屏或屏幕中央横向扫动，观众在成片里能一眼看出在“念稿”。

- **视觉解决方案**：
  - **打孔前摄邻近排版**：提词卡片强制贴紧屏幕顶部中央（或左上角前摄打孔点正下方），将文本有效阅读区收窄至屏幕宽度的 65%~70%。
  - **微小视差角**：创作者阅读文本时的视线与前摄光轴视差控制在 **3° 以内**，成片中眼球完全直视镜头，极为自然坚定。
- **界面结构拆解**：
  - **背景层**：CameraX 1080P/4K 全屏无畸变预览，可选 3x3 构图九宫格参考线；
  - **提词卡片**：70% 黑色半透磨砂玻璃（Blur 16dp），柔和高对比度白色字体，重点关键词支持黄色高亮显示；
  - **底部控制岛**：
    - 🔴 **醒目录制按钮**：带录制时长计数器（`00:01:24`）与红色呼吸指示圈；
    - ⏯️ **滚动暂停/继续**；
    - ⚡ **无级滚速滑块**（支持 0.5x ~ 2.5x 实时变速）；
    - 🔄 **前后摄像头一键翻转**。

## 2. 纯音频录制提词模式 (Audio Prompter Mode)

### 2.1 核心痛点突破：“发热掉电与拾音黑盒”
录制播客、旁白、有声书长文时，长时间开摄像头会导致手机发热降频乃至断录；普通录音软件又无法同时看稿。

- **视觉解决方案**：
  - **录音棚暗色模式 (Studio Dark Theme)**：背景采用深炭黑 (`#111318`)，关闭相机传感器，不仅超长录制不发热，在 OLED 屏幕上功耗几乎忽略不计；
  - **朗读焦点行指引线 (Active Reading Guide)**：居中提供暖珊瑚色高亮阅读基准框，上下文本平滑滑过，创作者只需将注意力放在基准线上，彻底消除换行迷失感。
- **界面结构拆解**：
  - **顶部信息**：节目/台本标题、录制耗时（大号等宽字体）；
  - **中部提词**：超大字号自适应滚动，支持行高调节与段落标色；
  - **声波监控卡片**：
    - **实时音频波形振幅条**：根据底层麦克风采样动态跳动，确认拾音状态正常；
    - **分贝计仪表**：提供峰值与防爆音电平指示（如 `-6dB` 正常，红区提示过载）；
  - **底部工作台**：
    - 麦克风录制/停止键、滚动暂停、字号微调面板、格式质量标签（`AAC 320kbps`）。

## 3. 设计规范参数 (Design Tokens)

| 维度 | 视频提词模式 | 音频提词模式 | 悬浮窗模式 |
| :--- | :--- | :--- | :--- |
| **底色** | 相机画面 + 暗色遮罩 | `#111318` 纯黑深色调 | 应用级浮窗 (`rgba(0,0,0,0.72)`) |
| **主强调色** | 录制红 (`#EF4444`) / 珊瑚橙 (`#F97316`) | 录音珊瑚橙 (`#FF6B4A`) / 荧光绿 (`#10B981`) | 翡翠绿 (`#34D399`) |
| **文本字号** | 16sp ~ 24sp (默认 18sp) | 18sp ~ 28sp (默认 22sp) | 13sp ~ 16sp (高密度) |
| **圆角** | 24dp (卡片) / 999dp (胶囊控制岛) | 20dp (卡片) / 999dp (按键) | 16dp (悬浮卡片) |
| **材质质感** | Backdrop Blur 16dp + 0.5dp 晶体高光边框 | 哑光磨砂深色实色 | 高穿透磨砂玻璃 |
