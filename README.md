# PromptFlow (语流提词器)

> 专为音视频创作者量身打造的极简、轻量、纯本地安卓提词工具。
> 告别忘词与眼神飘忽，一人团队高效完成口播、播客与演讲录制。

---

## 📌 项目定位 (Value Proposition)

针对短视频博主、播客创作者、演讲者与知识付费讲师的刚需工具。彻底摒弃市面同类产品臃肿庞大、强制登录、隐私窥探、弹窗广告泛滥的弊端，采用 **Local-first（本地优先）** 架构，提供秒级启动、丝滑滚动与多模态提词体验。

### 核心亮点
1. **多模态提词录制**：
   - 📹 **应用内视频拍摄提词**：前/后置摄像头预览，贴近镜头排布文本（优化直视眼神），支持 1080P/4K 高清录制。
   - 🎙️ **应用内纯音频录音提词**：无相机发热困扰，录音棚级高保真音频录制（支持波形监控、断点续录、标记点）。
   - 🪟 **系统级全局悬浮窗提词**：画中画悬浮窗覆盖在抖音、快手、小红书、自带相机或直播软件之上，随时随地提词。
2. **极简操作与专业控制**：
   - 无级滚动调速、字号/边距/透明度/镜像翻转调节。
   - 蓝牙无线遥控器适配（自拍杆按键、静音翻页笔操控开始/暂停/快进/倒退）。
3. **零云端依赖与绝对隐私**：
   - 台本、音视频数据全量驻留本地，无需联网即可离线运行，从根源保障用户创作者文案资产安全。

## 🛠️ 技术栈与依赖 (Tech Stack)

| 模块 | 技术选型 | 说明 |
| :--- | :--- | :--- |
| **开发语言** | Kotlin 2.0+ | 现代、空安全、全协程生态 |
| **UI 框架** | Jetpack Compose + Material 3 | 声明式响应式 UI，零 XML 冗余 |
| **视频采集** | AndroidX CameraX (1.4+) | 官方高兼容性相机库，支持 `Preview` 与 `VideoCapture` |
| **音频录制** | AndroidX Media3 / AudioRecord | 低延迟高保真音频采集与编码 (`.m4a` / `.wav`) |
| **全局悬浮窗** | Compose + WindowManager | 轻量级应用层悬浮窗，支持拖拽、吸边与手势穿透 |
| **本地存储** | Jetpack Room + DataStore | SQLite 本地结构化存储与键值偏好存储 |
| **架构规范** | 单工程模块化 MVVM / MVI + Clean Architecture | 逻辑解耦，一人长期零压力维护 |
